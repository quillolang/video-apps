# Text and Regular Expressions in Quillo: A Username Checker

Pick a handle: a sign-up that checks a username against its rules as you type (re.test), makes a web address from a post's title (normalize, re.replace, lower), and finds the hashtags in a bio (re.find_all). All of it runs in the browser.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
