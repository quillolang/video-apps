# Dates and Time Zones in Quillo: New Year's Midnight Around the World

Midnight around the world: New Year's midnight in nine cities, in the order it arrives, shown in a time zone you pick and counted down live. date.at, date.to_zone, date.format and date.ms, with every() for the clock and a ?at= time machine.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
