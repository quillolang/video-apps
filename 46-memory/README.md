# Build a Memory Game in One Quillo Component

Memory: twelve cards, six pairs, flip two at a time. The whole game is one component: its state, its clicks, a clock with every, and run_after to turn a miss back over.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
