# Change the code, keep the count | Quillo hot reload

The click counter from shorts/01-counter, for trying quillo run --watch: change its code while it runs, and the open page takes the new code and keeps its count.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
