# Type, and the page follows | Quillo

A greeter: an input's value={name} ties the text box to the state, both ways, and the greeting, the count and a surprise follow every key.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
