# Caught before it runs | quillo check

A greeting in two lines, for trying quillo check: pass a number where text belongs, or use || on a string, and it tells you before anything runs.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
