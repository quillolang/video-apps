# Post in one tab, see it in every tab | Quillo

A live wall: post in one tab, and every open tab shows it. A table, two server functions and a component, in one file.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
