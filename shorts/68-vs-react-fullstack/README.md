# A to-do list that saves: React + Express + SQLite vs one Quillo file

A to-do list that saves in SQLite, in one Quillo file: three server functions beside a component that calls them, and a migration. The Short sets it next to React, Express and better-sqlite3.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.

## The comparison

The video compares this app with the same one in another framework. [`compare/`](compare) holds that project, made
from its own starter (install its packages to run it), and [`compare/MEASURE.md`](compare/MEASURE.md) every command
behind the numbers in the video, with what it printed, the date, the machine and the versions.
