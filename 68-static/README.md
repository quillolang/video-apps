# A Whole Website With No Code, Against the Clock: quillo serve (Clean URLs, 404 Page) in 1:50.8

Mina's portfolio: four pages, a stylesheet and a 404 page, with no program at all. quillo serve site serves the folder as a static host does: index.html, clean URLs (/about finds about.html), a folder's address with its slash, 404.html for a miss, and no dot-files.

Written for Quillo 0.8.6 (get it at https://quillolang.org). Run it with:

```sh
quillo serve site
```
