# Possible or Not? 20 Questions About Quillo, Each Proved Live (Against the Clock)

Possible or not: twenty questions about Quillo, each with its proof, as one REPL session. Numbers (an int that overflows, dividing by zero, 7 // 2, 0.1 + 0.2 and 0.1m + 0.2m), text ("a" + 1, "ab" * 3, upper("straße"), .length), lists and maps (== on lists, [-1], past the end, push in place, a number as a key) and habits from other languages (zero, ===, ++, try, deep recursion).

Written for Quillo 0.8.6 (get it at https://quillolang.org). Run it with:

```sh
quillo repl < proofs.txt
```
