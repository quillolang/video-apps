# Quillo video apps

The sample apps from the [@quillolang](https://www.youtube.com/@quillolang) videos on YouTube, one folder per video.
Each runs with `./run.sh --watch` in its folder (it downloads the Quillo it was written for), then http://127.0.0.1:8080.

Quillo: https://quillolang.org

| Folder | Video | The app |
|---|---|---|
| [01-live-wall](01-live-wall) | A Live Full-Stack App in 50 Lines of Quillo | A live message wall: post in one tab, and every open tab shows it. One file, about 50 lines. |
| [02-crud-notes](02-crud-notes) | Build a Full CRUD App with Quillo: Notes, Live in Every Tab | A notes app: add, edit and delete notes, with validation, live in every open tab, and a JSON API. |
| [03-starter-app](03-starter-app) | A Tour of the Quillo Starter App (quillo new) | The to-do app `quillo new` makes, with the first change from the video: a Clear done button. |
| [04-composition](04-composition) | Components and Views in Quillo: Composing a Page | A café menu made of views and components: a frame, cards, a Stepper, and an order every card shares. |
| [05-reactivity](05-reactivity) | Reactivity in Quillo: State, Page State and live() | A focus board: a timer and a checklist with their own state, a focus switch in page state, and today's sessions, live for everyone. |
| [06-spa](06-spa) | A Single-Page App in Quillo: Links, url() and match | A recipe book as a single-page app: pages that change without reloading, a page per recipe at its own address, favourites kept while you move around, and real 404s. |
| [07-forms](07-forms) | Forms and Validation in Quillo: Typed Routes, 422s and Live Hints | A workshop sign-up: a plain form, a typed route that refuses the wrong shape, friendly messages for each field, seats counted in the database, and the same rules as hints while you type. |
| [08-hot-reload](08-hot-reload) | Hot Reload in Quillo: Edit While It Runs, Keep Your State | A game-night scoreboard to edit while it runs: two Score components, a Cheer button counted on the server, and a notes field. Run it with --watch, change it, and see what each save keeps. |
| [09-routes](09-routes) | Routes and Route Groups in Quillo: Params, Prefixes and Middleware | A little bookshop: pages found by typed routes, a JSON API in a routes group with a nested group inside, and an admin area behind middleware that sends you to log in first. |
| [10-split](10-split) | From Monolith to Services in Quillo: One Program, --split | A bakery that starts as one program, then moves its billing into a service: the same code runs in one process, or split into processes with --split, --scale and --watch, or on two servers with --service-url. |
| [11-project-structure](11-project-structure) | Project Structure in Quillo: One File to Many, use and import | A plant care list, split the way bigger programs are: main.qwe lists the parts, lib/ holds the helpers and server fns, ui/ the views and components, migrations/ the tables, data/ the database and public/ the files served as they are. |
| [12-state-let](12-state-let) | State vs let in Quillo: What Changes, What Follows, What's Shared | A tip splitter: what you change is state, what follows from it is let, and a top-level let on the server holds the tips paid, shared by every visitor until a restart. |
| [13-databases](13-databases) | Databases in Quillo: Migrations, Queries, Transactions and Live Pages | A team kudos board in SQLite: tables from migrations, queries with ? and :name values, rows checked against a record type, a unique name said plainly with db.error_kind, kudos given in a transaction that's all or nothing, and a board that follows the database live. |
| [14-request-response](14-request-response) | Request and Response in Quillo: What Comes In, What Goes Out | Snippets, a tiny API: one route that echoes what a request holds, and routes that answer with text, HTML, JSON with an etag (and a 304), 201 with a location, 204, a 301 redirect, and an error value's 500. |
| [15-components](15-components) | Components from quillolang.org: 877 Ready-Made UI Components | Café feedback, made with components downloaded from quillolang.org/components: Rating as a form field and as a read-only summary, Alert for the thanks, and theme.qwe's variables to restyle them all. |
| [17-language](17-language) | The Quillo Language in One Sitting: What Happens If...? | Fortune cookies: a little of everything from the language tour (a record type, a list, match, a template string and a query pattern) in one small program. The tour itself is tour.txt, for quillo repl. |
| [18-no-fetch](18-no-fetch) | No fetch in Quillo: Call the Server Like a Function | A live lunch poll whose buttons call the server like plain functions: no API route, no fetch, no JSON, no async/await, no try/catch, and every open tab follows the votes with live(). |
| [19-no-async](19-no-async) | No async/await in Quillo: Waiting Without the Ceremony | A pizza tracker waiting on slow kitchens with no async and no await: calls one after another, parallel() to overlap their waits, a server that answers other requests meanwhile, and a page whose click handler waits three times without freezing. |
| [20-headers-cookies](20-headers-cookies) | Headers, Cookies and Sessions in Quillo: The Treehouse Club | The treehouse club: a greeting in the browser's own language from accept-language, a day or night theme kept in a cookie, members kept in a signed session that can't be forged, and a secret door that opens to the right knock header. |
| [21-records](21-records) | Records and Types in Quillo: Build an RPG Character Sheet | Hero forge, an RPG character sheet whose types catch bad stats: string unions for classes, defaults, nested records, a JSON route that only takes a Hero, and fields a client adds dropped on the way in. |
| [22-match](22-match) | Pattern Matching Speedrun: Rock Paper Scissors in Quillo | Rock paper referee: rock, paper, scissors against a sneaky computer that plays whatever beats your last move, with every rule written as a match: guards, alternatives, list patterns and map patterns. |
| [23-errors](23-errors) | Bug Hunt: Errors as Values in Quillo (a Vending Machine) | Snack-o-matic, a vending machine where every failure is a value: no such slot, sold out, not enough money. The video starts from a broken copy with two bugs (an error that isn't text, and a dropped error that sells crisps for 50¢) and fixes them; this is the fixed one. |
| [24-pipes](24-pipes) | Lists and Maps Without Mutation in Quillo: An Arcade High-Score Table | Comet Catcher high scores: a leaderboard built with pipes (group_by, values, map, sort_by), medals from a match, and new scores added with plays = plays | push(...), since nothing in Quillo changes in place. |
| [25-money](25-money) | Money in Quillo: A Lemonade Stand Till That Never Loses a Cent | Lemon Aid, a lemonade stand's till: prices as exact decimals, tax rounded to the cent with money.mul, a bill split between friends with money.allocate so no cent is lost or made, and sales priced by the server's own menu. |
| [26-channels](26-channels) | Real Time with Channels in Quillo: A Live Emoji Reaction Wall | Cheers!, a talk's live reaction wall: tap an emoji and it floats up on every open page. The server counts with channel.on and channel.broadcast, join and leave keep a count of who's watching, and each page listens with channel.open. |
| [27-live](27-live) | Live Data in Quillo, Deeper: A Silent Auction with Watch and Publish | Bid for Good, a charity's silent auction: a board that follows every bid with live(all_items), item pages that follow only their own item with live(one_item, id), watch and unwatched, and bids that publish the item's topic. |
| [28-streaming](28-streaming) | Streaming in Quillo: A Rocket Countdown with Server-Sent Events | Mission Control: a crew briefing that types itself out, streamed word by word with stream, and a launch countdown sent as Server-Sent Events with events, read on the page with receive. |
| [29-jobs](29-jobs) | Scheduled Jobs in Quillo: Houseplants That Ask for Water | Plant Pal: houseplants that ask for water. A job on a schedule finds the thirsty ones and leaves a note, pages follow the plants live, and a clock on the page counts down to the next check with every. |
| [30-uploads](30-uploads) | File Uploads in Quillo: Build a Pet Photo Wall | Pet wall: visitors upload photos of their pets with a multipart form. The route checks the kind and size again, saves each file under a name it makes with save_upload, keeps the captions in SQLite, and serves the photos with files(). |
| [31-markdown](31-markdown) | A Blog from Markdown Files in Quillo: The Pancake Diaries | The Pancake Diaries: a blog whose posts are Markdown files. Each post is read on every request and made HTML with markdown() inside the blog's own page; the about page is a whole page from markdown_page(); only posts on the list are served. |
