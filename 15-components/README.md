# Components from quillolang.org: 877 Ready-Made UI Components

Café feedback, made with components downloaded from quillolang.org/components: Rating as a form field and as a read-only summary, Alert for the thanks, and theme.qwe's variables to restyle them all.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
