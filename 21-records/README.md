# Records and Types in Quillo: Build an RPG Character Sheet

Hero forge, an RPG character sheet whose types catch bad stats: string unions for classes, defaults, nested records, a JSON route that only takes a Hero, and fields a client adds dropped on the way in.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
