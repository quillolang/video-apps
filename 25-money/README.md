# Money in Quillo: A Lemonade Stand Till That Never Loses a Cent

Lemon Aid, a lemonade stand's till: prices as exact decimals, tax rounded to the cent with money.mul, a bill split between friends with money.allocate so no cent is lost or made, and sales priced by the server's own menu.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
