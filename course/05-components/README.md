# Click! Components and State | Learn to Code with Quillo #5

Movie Night, lesson 5 of Learn to Code with Quillo: a VoteButton component on each movie's page, with its votes in state, a word that follows them, and a Reset button.

This lesson starts where [04-functions](../04-functions) ended.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.

## The versions in the video

The video builds this app up step by step. Each step is a folder that runs on its own (`cd steps/v1 && ./run.sh --watch`):

- [`steps/v0`](steps/v0): where lesson 4 ended
- [`steps/v1`](steps/v1): a VoteButton component: state votes, and onclick
- [`steps/v2`](steps/v2): "vote" or "votes": a let that follows the state
- this folder: a Reset button (the lesson's "your turn")
