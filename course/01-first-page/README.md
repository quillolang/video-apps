# Your First Web Page | Learn to Code with Quillo #1

Movie Night, lesson 1 of Learn to Code with Quillo: a web page with a heading and two paragraphs, made by one route.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.

On Windows, in PowerShell, in this folder:

```powershell
curl.exe -fsSLO https://raw.githubusercontent.com/quillolang/starter/v0.8.6/get-quillo.ps1
powershell -ExecutionPolicy Bypass -File get-quillo.ps1
.\run.cmd --watch
```

Quillo gets updates: the official install page, https://quillolang.org/docs/install/, always has the latest.

## The versions in the video

The video builds this app up step by step. Each step is a folder that runs on its own (`cd steps/v1 && ./run.sh --watch`):

- [`steps/v1`](steps/v1): the one-line page: a heading
- [`steps/v2`](steps/v2): a heading and a paragraph, across a few lines
- this folder: a second paragraph (the lesson's "your turn")
