# API Docs for Free: quillo docs and OpenAPI

Plant care: a small JSON API for the office plants, and a docs page made from its own OpenAPI description. Run it with ./run.sh --describe and open /docs; quillo docs main.qwe prints the same description.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
