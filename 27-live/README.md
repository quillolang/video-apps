# Live Data in Quillo, Deeper: A Silent Auction with Watch and Publish

Bid for Good, a charity's silent auction: a board that follows every bid with live(all_items), item pages that follow only their own item with live(one_item, id), watch and unwatched, and bids that publish the item's topic.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
