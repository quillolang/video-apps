# Bug Hunt: Effects in Quillo (What Your Page Is Allowed to Do)

Joke of the day: one joke a day, the same all day, from SQLite. Its page is declared with db, time, so it may use the database and the clock and nothing else. The video starts from a teammate's version whose helpers pick at random, post to a stats site and write a file, and fixes each one.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
