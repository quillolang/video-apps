# Streaming in Quillo: A Rocket Countdown with Server-Sent Events

Mission Control: a crew briefing that types itself out, streamed word by word with stream, and a launch countdown sent as Server-Sent Events with events, read on the page with receive.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
