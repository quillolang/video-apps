# [] == ![] Is true? 16 JavaScript Surprises, Tried in Quillo

JavaScript's famous surprises, asked in Quillo: a script that prints Quillo's answer to each (0.1 + 0.2, a big int, max of nothing, NaN, "5" + 2, parseInt and map, [] == ![], [1, 2] == [1, 2], typeof null, 0 || "none", sort, lists added). The video asks each in node -p and in quillo repl. Three that stop with an error in Quillo ("5" - 2, February 31st and +"a") are left out of the script. quillo check warns about 0 || "none", on purpose.

Written for Quillo 0.8.6 (get it at https://quillolang.org). Run it with:

```sh
quillo run main.qwe
```
