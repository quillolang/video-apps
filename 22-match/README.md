# Pattern Matching Speedrun: Rock Paper Scissors in Quillo

Rock paper referee: rock, paper, scissors against a sneaky computer that plays whatever beats your last move, with every rule written as a match: guards, alternatives, list patterns and map patterns.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
