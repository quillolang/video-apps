# Build a Cannon Game with Sine and Cosine in Quillo (math.sin, math.cos, every)

Cannon: pick an angle and a power, fire, and hit the target. math.cos and math.sin split the shot into across and up, the ball's place comes straight from the formula at time t, and every, under an if, runs the clock only while the ball flies.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
