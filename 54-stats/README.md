# One Zero Fooled the Average: Mean, Median, Mode and Spread in Quillo

A report card for a class quiz: stats.mean, median, mode and pstdev, a grade histogram, and zscore to mark who stands out, all worked out in the browser as a score is typed. Theo's zero, and then his retake, show how one far-off score pulls the mean and hides who needs help.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
