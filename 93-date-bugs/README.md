# January 31 Plus One Month Is March 3rd? 5 Date Bugs in Every Subscription App

Flex & Flow's renewals, a Quillo script: each member's next renewal, counted in months from the day they joined, and the days until it, from a fixed today (2026-02-15). Ada joined on January 31st and renews on February 28th; Linus's date comes from a UK form, 03/04/2026, read day first as April 3rd. The video shows five date bugs in JavaScript (in New York's time zone) and the same questions asked of Quillo's date functions.

Written for Quillo 0.8.6 (get it at https://quillolang.org). Run it with:

```sh
quillo run main.qwe
```
