# The Quillo Language in One Sitting: What Happens If...?

Fortune cookies: a little of everything from the language tour (a record type, a list, match, a template string and a query pattern) in one small program. The tour itself is tour.txt, for quillo repl.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
