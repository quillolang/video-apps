# Conway's Game of Life in One Quillo Component (Click, Play, Speed Slider)

Conway's Game of Life in one component: a 40 by 26 grid that wraps around, four rules in a function called next, cells you click to bring to life, a glider and the R-pentomino to start from, and every running the generations at the speed a slider says.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
