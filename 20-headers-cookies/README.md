# Headers, Cookies and Sessions in Quillo: The Treehouse Club

The treehouse club: a greeting in the browser's own language from accept-language, a day or night theme kept in a cookie, members kept in a signed session that can't be forged, and a secret door that opens to the right knock header.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
