# A Tour of the Quillo Starter App (quillo new)

The to-do app `quillo new` makes, with the first change from the video: a Clear done button.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.

## The versions in the video

The video builds this app up step by step. Each step is a folder that runs on its own (`cd steps/v1 && ./run.sh --watch`):

- [`steps/v1`](steps/v1): the starter app, just as `quillo new hello` makes it
- this folder: the starter app with the Clear done button
