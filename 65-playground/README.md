# A Quillo Playground, Written in Quillo: Checker Errors as You Type (check_program)

A Quillo playground written in Quillo: type a program, and a server fn runs the same checker as quillo check on the text (check_program), at every keystroke, to show its errors and warnings: typos, wrong types, and JavaScript habits. Four examples to start from.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
