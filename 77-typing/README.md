# A Typing Speed Test, Against the Clock (1:40.6) | Quillo Speedrun

Tap Tap, a typing test in one component: a line to type, each letter green or red as you go, a clock that starts at your first key (every() while typing), and your words a minute and how many keys were right at the end.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
