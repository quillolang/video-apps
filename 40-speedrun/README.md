# Speedrun: a To-Do App in 2:12 (Quillo, any%)

A to-do list kept in a database: add, tick, delete, three tabs and clear done. Written against the clock from quillo new --minimal, in four files: the table, the server fns (lib/todos.qwe), the component (ui/todos.qwe) and the page.

Written for Quillo 0.8.6. `run.sh` downloads that Quillo the first time:

```sh
./run.sh --watch
```

Then open http://127.0.0.1:8080.
